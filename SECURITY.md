# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, pull
request, discussion, or recording.

Use GitHub's private vulnerability-reporting option for the affected repository
when it is available. Otherwise, contact
[@BenHarris11](https://github.com/BenHarris11) through GitHub and request a
private reporting channel before sharing technical details.

Include the affected repository and version, reproduction conditions, impact,
and any suggested mitigation. Do not include real user data, credentials, or
private device recordings.

## Supported versions

Kyntex is an active prototype. Security fixes are applied to the latest code on
the default branch; older prototypes and archived releases are not supported.

## Scope

Reports concerning firmware update integrity, BLE access control, data export,
local session storage, or accidental disclosure of private implementation
details are especially useful.
