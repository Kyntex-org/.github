# Kyntex

Kyntex is a wearable sensing project focused on tracking relative patellar tendon stiffness during training, recovery, and return-to-sport progression.

## Public Repositories

- [Kyntex](https://github.com/Kyntex-org/Kyntex) — Main public project repository
- [Kyntex Technical Public](https://github.com/Kyntex-org/Kyntex-Technical-Public) — Public technical documentation and notes

## Developer

Created and maintained by [Ben Harris](https://github.com/BenHarris11).

## Status

Kyntex is currently in development. Some repositories may remain private while active work is ongoing.

Kyntex is an early-stage prototype and is not a medical device.
