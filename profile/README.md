Kyntex is an independent wearable-sensing project focused on trustworthy training
telemetry: motion and band-fit sensing, visible recording integrity, and
reviewable workout history.

Created by [Ben Harris](https://github.com/BenHarris11), co-founder and sole
engineer, with work spanning firmware, Bluetooth protocols, companion
applications, and custom PCB design.

## Project status

Kyntex is an engineering prototype built around Nordic nRF54L15/Zephyr, a
versioned BLE transport, a SwiftUI iOS app, and a browser engineering dashboard.
The current iOS experience stores workouts locally without a Kyntex account.
Production development remains private; public software is deliberately selected
and the dashboard demo uses synthetic data.

See the [dated validation evidence and remaining release work](https://github.com/Kyntex-org/Kyntex-Technical-Public/blob/main/docs/validation-status.md)
and [development roadmap](https://github.com/Kyntex-org/Kyntex-Technical-Public/blob/main/docs/roadmap.md).
Tendon-response sensing remains exploratory. Kyntex is not a medical device and
is not intended to diagnose, treat, prevent, or predict injury.
